FastAPI utilise des modèles Pydantic pour valider les corps de requêtes JSON, et génère aussi automatiquement une 
documentation interactive de l’API, ce qui est exactement ce qu’on va utiliser pour tester /predict.


__init__.py -> Il peut rester vide. Il sert juste à dire à Python que app est un package importable.

schemas.py -> Ce fichier sert à définir les formats d’entrée/sortie de ton API.

model_service.py -> Ce fichier est le cœur IA de l'API : il charge le model via mlflow, récupère les labels, calcule les probabilités, puis transforme les probabilités en 0 ou 1.

main.py -> permet de créer les routes

Api fonctionnelle avec : 

GET /
GET /health
POST /predict


commande de lancement de l'api : uvicorn app.main:app --reload


Ensuite, ouvre dans ton navigateur :

http://127.0.0.1:8000/docs
